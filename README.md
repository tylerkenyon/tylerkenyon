# Tyler Kenyon

Software developer working on FOSS Minecraft tooling and small, self-contained utility apps — one job per tool, no dependencies where I can avoid them.

## Featured projects

| Project | What it is |
|---|---|
| [Logic-Client](https://github.com/tylerkenyon/Logic-Client) | Injected, free and open-source Minecraft client for 26.2 (Java + Rust injector) |
| [mica](https://github.com/tylerkenyon/mica) | Dear ImGui overlay library for Minecraft 26.2+, sitting on Vulkan with a Minecraft-side render backend |
| [Notro-Client-Addon](https://github.com/tylerkenyon/Notro-Client-Addon) | Hooks the Notro Client event bus and module manager so you can write custom modules |

## Small tools

One-purpose CLI and desktop tools:

- [passgen](https://github.com/tylerkenyon/passgen) — random passwords with an entropy estimate
- [dupfind](https://github.com/tylerkenyon/dupfind) — find duplicate files by sha256
- [cliphist](https://github.com/tylerkenyon/cliphist) — clipboard history in your system tray
- [split](https://github.com/tylerkenyon/split) — split bills with a persistent ledger, see who owes who
- [typist](https://github.com/tylerkenyon/typist) — typing trainer for real code, not prose
- [lan-share](https://github.com/tylerkenyon/lan-share) — share a folder over your LAN with a QR code
- [convert](https://github.com/tylerkenyon/convert) — json/yaml/toml/csv converter, pipe friendly, no deps
- [star-notifier](https://github.com/tylerkenyon/star-notifier) — desktop notification when your repos get starred or forked
- [gh-heatmap](https://github.com/tylerkenyon/gh-heatmap) — your GitHub contribution graph as an ASCII heatmap in the terminal
- [git-dashboard](https://github.com/tylerkenyon/git-dashboard) — one table showing branch, ahead/behind, dirty state for all your repos
- [shell-cheatsheet](https://github.com/tylerkenyon/shell-cheatsheet) — tldr-style cheatsheet generated from your own shell history
- [System-Shutdown-Timer](https://github.com/tylerkenyon/System-Shutdown-Timer) — schedule a Windows shutdown
- [Telegram-Downloader](https://github.com/tylerkenyon/Telegram-Downloader) — download Telegram files with Discord integration
- [Gitbook-Downloader](https://github.com/tylerkenyon/Gitbook-Downloader) — download Gitbook sites for offline reading
- [SVG-Parser](https://github.com/tylerkenyon/SVG-Parser) — parse SVG files from a Python CLI
- [Watermarker](https://github.com/tylerkenyon/Watermarker) — add watermarks to images
